<p>صاحب امتیاز: انجمن علمی مهندسی کامپیوتر دانشگاه صنعتی شیراز 👾<br>
مدیر مسئول 👤: محمد رضائی<br>
سردبیر 📝: امیرحسین خدیوی خانقاه</p>

<h2>آنچه در این شماره می‌خوانید 📜</h2>

<h3>خانه‌های هوشمند 🏠</h3>
<ul>
  <li>قطعات و زیرساخت‌ها</li>
  <li>ارتباط میان وسایل و تهدیدهای امنیتی</li>
  <li>کاربرد الگوریتم‌ها و ربات‌های هوشمند</li>
  <li>چشم‌انداز بازار کار این فناوری</li>
</ul>

<p><strong>پرسش‌های محوری:</strong></p>
<ul>
  <li>خانه هوشمند؛ نیاز واقعی یا فقط یک تجمل؟</li>
  <li>خانه هوشمند؛ نزدیک شدن به دنیای فیلم‌های علمی-تخیلی یا یک ضرورت؟</li>
</ul>
